# McDonald's Menu Analytics Dashboard - Power BI

## Project Overview

This project is a Power BI dashboard analyzing McDonald's menu and nutrition data.

The dashboard helps explore menu categories, product-level nutrition values, and key nutrition metrics such as calories, protein, sodium, sugar, and fat.

## Dataset

The dashboard uses a McDonald's menu and nutrition dataset with fields such as:

- Product name
- Category
- Serving unit
- Calories
- Protein
- Sodium
- Sugar
- Fat

## Tools Used

- Power BI
- Power Query
- DAX
- GitHub

## Key Insights

This dashboard can be used to analyze:

- Menu items by category
- Calories across products
- Protein, sodium, sugar, and fat comparison
- Category-wise nutrition patterns
- Individual product nutrition details

## Purpose

This project was created as a Power BI portfolio project to demonstrate dashboard design, interactive reporting, and nutrition data analysis.
